# 10 000 Hours 1.0.0 — ручная проверка на физическом iPhone

Отмечайте пункт только после проверки на реальном устройстве. Пункты с **[только устройство]** нельзя надёжно проверить на симуляторе (Live Activity и Dynamic Island, доставка уведомлений, обновление виджетов системой, работа в фоне).

Подготовка: iPhone с iOS 17+ (желательно с Dynamic Island), сборка Release через TestFlight или Xcode, уведомления и Live Activities не трогались до установки.

## 1. Чистая установка
- [ ] Удалить приложение, установить заново, открыть.
  Ожидается: главная, таймер `00:00`, `0,00%`, `0 / 10 000 ч`, пустая сетка; история «Сессий пока нет». Системных запросов при первом запуске нет.
- [ ] Иконка на домашнем экране и в Настройках.
  Ожидается: иконка из Figma («флаг и точки»), белый фон, углы скругляет система, название «10 000 Hours».

## 2. Play / Stop
- [ ] Play.
  Ожидается: таймер идёт, кнопка — Stop; один раз появляется запрос на уведомления.
- [ ] Stop раньше 60 секунд.
  Ожидается: таймер сбрасывается, в истории записи нет.
- [ ] Play → подождать больше минуты → Stop.
  Ожидается: в истории запись с верной длительностью, прогресс увеличился.
- [ ] Быстро нажать Play/Stop несколько раз подряд.
  Ожидается: не больше одной активной сессии, интерфейс не зависает.

## 3. Работа таймера в фоне **[только устройство]**
- [ ] Play → свернуть приложение на 5 минут → открыть.
  Ожидается: таймер показывает ≈5 минут, отсчёт не прерывался.
- [ ] Play → заблокировать экран на 10 минут → разблокировать.
  Ожидается: время верное; на экране блокировки шла Live Activity.

## 4. Восстановление после принудительного завершения
- [ ] Play → смахнуть приложение из переключателя → через 2 минуты открыть.
  Ожидается: сессия продолжается, время считается от момента Play.
- [ ] Перезагрузить iPhone при идущем таймере → открыть приложение. **[только устройство]**
  Ожидается: сессия продолжается, время верное.

## 5. История и редактирование
- [ ] Открыть «Историю».
  Ожидается: сессии от новых к старым, дата и длительность в русском формате.
- [ ] Изменить длительность (часы и минуты) → «Сохранить».
  Ожидается: значение в списке обновилось, на главной изменились процент, часы и сетка.
- [ ] Ввести 0 ч 0 мин или минуты > 59.
  Ожидается: «Сохранить» недоступна, показана подсказка.
- [ ] Изменить значение → «Отмена».
  Ожидается: длительность прежняя.
- [ ] Отредактировать сессию при идущем таймере.
  Ожидается: таймер не сбросился.

## 6. Small / Large Widget **[только устройство]**
- [ ] Добавить Small и Large виджеты на домашний экран.
  Ожидается: вид как в Figma; Large показывает процент и часы.
- [ ] Play в Small Widget, приложение закрыто.
  Ожидается: виджеты показывают Stop, появляется Live Activity; при открытии приложения таймер идёт.
- [ ] Stop в Large Widget.
  Ожидается: сессия сохраняется (или отбрасывается, если короче 60 с), Live Activity исчезает.
- [ ] Play в приложении → вернуться на домашний экран.
  Ожидается: виджеты показывают Stop (WidgetKit может обновлять их с небольшой задержкой).
- [ ] Изменить длительность в истории.
  Ожидается: процент в Large Widget обновился.

## 7. Live Activity **[только устройство]**
- [ ] Play → экран блокировки.
  Ожидается: одна Live Activity, таймер идёт.
- [ ] Stop с экрана блокировки.
  Ожидается: activity исчезает, сессия есть в истории.
- [ ] Быстро Play → Stop → Play из приложения.
  Ожидается: ровно одна activity для текущей сессии.
- [ ] Выключить Live Activities в Настройках → Play.
  Ожидается: таймер и виджеты работают без activity.

## 8. Dynamic Island **[только устройство с Dynamic Island]**
- [ ] Play → свернуть приложение.
  Ожидается: compact-вид с таймером; при двух activity — minimal.
- [ ] Долгое нажатие — expanded, нажать Stop.
  Ожидается: сессия сохраняется, остров исчезает.

## 9. Уведомления **[только устройство]**
- [ ] Отказать в разрешении при первом Play.
  Ожидается: приложение работает, повторных запросов нет.
- [ ] Разрешить уведомления; не запускать таймер; дождаться 20:00 (или перевести время).
  Ожидается: одно уведомление «Даже 1 минута ближе к 10 000, чем 0 минут».
- [ ] Запустить таймер днём (из приложения или виджета).
  Ожидается: в 20:00 этого дня уведомления нет.
- [ ] Нажать на уведомление.
  Ожидается: открывается вкладка «Главная», таймер не запускается.

## 10. Достижение цели
Удобнее проверить на тестовой сборке: в истории отредактировать сессию до 10 000 ч.
- [ ] Сохранить 10 000 ч.
  Ожидается: поздравление; после «Закрыть» вместо Play — «Начать заново»; виджеты без Play; уведомлений больше нет.
- [ ] Уменьшить длительность ниже 10 000 ч.
  Ожидается: снова Play, напоминания возвращаются.
- [ ] Достичь цели Stop-ом из виджета или Live Activity → открыть приложение.
  Ожидается: показывается поздравление.

## 11. Сброс
- [ ] «Начать заново» → «Отмена».
  Ожидается: данные не изменились.
- [ ] «Начать заново» → подтвердить.
  Ожидается: история пустая, `0,00%`, виджеты и Live Activity обновились, Play доступен.
- [ ] Закрыть и открыть приложение.
  Ожидается: состояние после сброса сохранилось.

## 12. Сохранность данных
- [ ] Накопить несколько сессий → обновить приложение поверх (новая сборка TestFlight).
  Ожидается: история и прогресс сохранились.
- [ ] Перевести системное время назад при идущем таймере.
  Ожидается: длительность не уходит в минус; Stop отбрасывает такую сессию как короткую.

## Accessibility
- [ ] VoiceOver: таймер, Play/Stop, сетка (одна сводка), строки истории, виджеты.
- [ ] Максимальный размер текста: текст не обрезается, кнопки доступны.
- [ ] «Увеличение контраста»: элементы различимы.
